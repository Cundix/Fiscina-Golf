# El Verde

Proyecto escolar de Desarrollo Web sobre campos y figuras del golf.

- [Sitio publicado](https://cundix.github.io/Fiscina-Golf/)
- [Repositorio](https://github.com/Cundix/Fiscina-Golf)
- [Texto de presentación](docs/presentacion.txt)
- [Créditos de fotografías y fuentes](docs/creditos.html)

## Archivos

```text
index.html          Contenido de la página
styles.css          Estilos y adaptación a pantallas
script.js           Menú para celulares
assets/images/      Fotografías locales en WebP
assets/fonts/       Tipografía Inter y su licencia
docs/               Texto de presentación y créditos
```

Se puede abrir `index.html` directamente en un navegador. No requiere instalar dependencias. Las imágenes, la tipografía y los estilos se incluyen en el proyecto.

## GitHub Pages

La publicación utiliza la rama `main` y la carpeta raíz (`/`). La página principal es `index.html`. Para actualizar el sitio se suben los cambios a la misma rama y se espera a que finalice el despliegue de Pages.
