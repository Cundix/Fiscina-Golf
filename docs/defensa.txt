GUÍA PARA LA DEFENSA

1. Tema y objetivo
El Verde presenta seis campos y ocho figuras del golf. Está pensado como una introducción visual para personas interesadas en el deporte.

2. Estructura
index.html contiene el contenido. Las etiquetas header, nav, main, section y footer separan las partes. Cada enlace del menú utiliza # y el id de una sección para navegar dentro de la misma página.

3. Estilos
styles.css controla la apariencia. Las variables de :root reúnen los colores y la tipografía. Grid distribuye las tarjetas en columnas; Flexbox alinea elementos como la cabecera y los botones. Las media queries cambian la distribución según el ancho disponible.

4. Celular
En pantallas pequeñas las tarjetas se apilan y aparece un botón de menú. script.js escucha los clics y cambia la clase is-open. aria-expanded informa si el menú está abierto. Escape lo cierra. Sin JavaScript, los enlaces siguen visibles.

5. Imágenes
Las rutas son relativas, por ejemplo assets/images/augusta.webp. Así funcionan dentro de la carpeta del repositorio y en GitHub Pages. Las imágenes secundarias usan loading="lazy" para cargarse cuando se necesitan. Los textos alt describen su contenido.

6. Publicación
GitHub almacena el código y su historial. GitHub Pages sirve los archivos como una página pública. Tener el repositorio subido y tener el sitio publicado son dos pasos diferentes.

7. Revisión final
Se comprobaron los destinos del menú, las rutas de imágenes y estilos, los nombres de archivo y la adaptación a distintos tamaños. Se eliminaron enlaces sin destino y controles que no tenían un servicio conectado.

Antes de presentar, abrí index.html y styles.css, ubicá cada ejemplo y practicá explicarlo con tus propias palabras. Ajustá el texto de presentación para que refleje tu experiencia.
